# Clinical Outpatient Analytics Dashboard  
*Dashboard and predictive analysis of outpatient consultations.*

---

## 📌 Project Overview

This project analyzes outpatient consultations using simulated healthcare data.  
The workflow includes:

- Data cleaning and preparation  
- Exploratory data analysis (EDA)  
- SQL analytical queries  
- Power BI interactive dashboards  
- A machine learning model for *no-show prediction*

The goal is to demonstrate how hospital decision-making can be supported through data analytics and predictive modeling.

---

## 🎯 Objectives

- Build a clean and structured outpatient dataset  
- Develop a reproducible ETL workflow using Python  
- Create SQL queries for operational insights  
- Build a multi-page dashboard in Power BI  
- Implement and evaluate a predictive model  
- Document the project for technical and professional review

## 📊 Dashboard Insights

The Power BI dashboard will include:

- Total consultations  
- Waiting time distribution  
- Consultations by specialty  
- Heat map by hour and day  
- Top diagnoses and reasons for visit  
- Patient no-show behavior

## 🤖 Machine Learning Component

A baseline model will be implemented to predict appointment no-shows.

**Model:** Logistic Regression  
**Metrics:** Accuracy, ROC-AUC, Confusion Matrix
